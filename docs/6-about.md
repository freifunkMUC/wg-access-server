# About

wg-access-server was started by [James Batt (place1)](https://github.com/Place1/wg-access-server) in
2019. When the original project stopped being maintained, [Freifunk München](https://ffmuc.net/)
continued it in this fork: keeping it up to date and secure, and adding what our users asked for -
IPv6, several server replicas sharing one database, renaming devices, API tokens and more.

It is free software under the [MIT License](https://github.com/freifunkMUC/wg-access-server/blob/master/LICENSE).

## Getting involved

- **Questions, ideas and bugs**: open an
  [issue](https://github.com/freifunkMUC/wg-access-server/issues). Tell us what you would like to
  see - that is how most features got here.
- **Code and docs**: pull requests are welcome. The [README](https://github.com/freifunkMUC/wg-access-server#development)
  explains how to build and test the project.
- **Security problems**: please do not open an issue. Report them privately through
  [GitHub's vulnerability reporting](https://github.com/freifunkMUC/wg-access-server/security/advisories/new),
  so that a fix can be released before the problem is public.
